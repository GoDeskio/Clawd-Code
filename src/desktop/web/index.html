First-run setup

Jonathan Ai is the agent. Chat works with one API key or a local LLM — MCP, Cursor, and Codex are optional and not required. Keys stay only in ~/.clawd/config.json (mode 0600). They are never written into git or the installer.

Provider & model

Hugging Face and Local LLM sit beside Anthropic, OpenAI, GLM, and Minimax. Switching providers does not require a reinstall.

Source and updates: https://github.com/GoDeskio/Clawd-Code. Default local tree: ~/Jonathan/Jonathan-Ai.

Git & other agents

Optional. Jonathan Ai chats on its own. Connect MCP or another agent only if you already run one. Tokens stay in ~/.clawd/config.json. Jonathan Ai never pushes main/master unless you name that branch. Default GitHub owner is GoDeskio.

MCP servers
