# Writing polish

Improve the draft without inventing a different author or argument. Treat a supplied voice sample or style guide as the strongest style signal, but do not copy distinctive passages.

## Work in two passes

1. **Surface:** remove filler, canned transitions, vague praise, repetition, inflated claims, unnecessary signposting, and punctuation habits that flatten the voice. Prefer concrete nouns and direct verbs where they preserve the intended tone.
2. **Structure:** inspect paragraph purpose, opening pattern, information order, cadence, repeated sentence shapes, and whether every point resolves too neatly. Change only the structures that weaken this particular piece; do not replace one formula with another.

For technical, legal, financial, medical, academic, or factual material, preserve terminology, qualifications, citations, numbers, and uncertainty unless the user explicitly asks to change substance. Never fabricate personal anecdotes, lived experience, sources, or named details to make prose seem human.

## Deliverable

Return the polished text first. Then briefly identify material changes, any ambiguity that was intentionally left unresolved, and any factual statement that still needs verification. If the user asks for edits in a file, preserve its format and make a reviewable copy unless they explicitly request an overwrite.

Do not claim the result is undetectable or provide a detector score. If the request is to misrepresent authorship in a graded, contractual, legal, or employment context, help improve clarity and voice while keeping authorship and disclosure accurate.
